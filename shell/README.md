# noobty-shell (planned, M3)

Windows tray shell built with **Tauri 2**. It embeds the hub's web UI and adds:

- system notifications on incoming transfers
- auto-accept (save incoming files to `Downloads\Noobty`)
- drag-and-drop sending
- a host for future toolbox features (clipboard sync, device management, ...)

The shell does **not** have its own UI — everything visible is the hub's web page, so there is never a second UI to maintain.
